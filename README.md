# Inetixus portfolio

Live at https://inetixus.it. This repository contains the static website served by Vercel; no build command is required. Run a static HTTP server from the repository root to preview it locally.

Project content and package amounts are in site-content.json. The client account pages are /login/, /signup/, and /forgot-password/. They are UI previews only: Google and email authentication are not connected and no credentials are transmitted or saved. See AUTH_SETUP.md for the setup needed to enable accounts.

The avatar uses the owner's actual Roblox model and textures. Its body transforms match the supplied pose reference, and accessories follow their parent parts. The background floor cubes persist and tilt through pricing. No generated images are used.
